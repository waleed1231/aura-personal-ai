# AURA Personal AI 🤖

AURA is a personal AI assistant project designed to support everyday tasks through an interactive interface, multilingual communication, and voice-based interaction.

## ✨ Features

- Interactive AI assistant interface
- React + Vite frontend
- Python FastAPI backend
- Multilingual interaction: Urdu, Hindi, and English
- Voice input and spoken responses
- Language-switching commands
- Modular architecture for future improvements

## 🛠️ Tech Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS

**Backend**
- Python
- FastAPI
- OpenAI API integration

## 📁 Project Structure

```text
personal-ai-agent/
├── backend/

```

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/waleed1231/aura-personal-ai.git
cd aura-personal-ai
```

### 2. Set up the backend

Install Python dependencies using the project's requirements file, if provided.

Create a local `.env` file for the required configuration. Never publish API keys or passwords.

### 3. Set up the frontend

```bash
cd frontend
npm install
npm run dev
```

Follow the backend configuration and startup instructions for your local setup.

## 🔐 Security

- Keep API keys and secrets in environment variables.
- Never commit `.env` files.
- Configure production CORS and authentication before deployment.
